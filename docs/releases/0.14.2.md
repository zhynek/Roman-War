# Roman War 0.14.2 — one Mac app

[Download Roman War for Mac](https://github.com/zhynek/Roman-War/releases/download/v0.14.2/Roman-War-macOS-0.14.2.zip)

Unzip and open **Roman War.app**. The universal binary includes Apple Silicon
and Intel; no Godot installation is required.

## Campaign and Alpine Route are now together

- **Begin the Campaign** uses the selected house, difficulty and world seed.
- **Play the Alpine Route** starts the authored Julii forest/bridge/marsh/pass
  route using the same campaign engine and realistic terrain.
- **Options → Return to main menu** lets you switch modes without restarting
  the app. The confirmation warns about unsaved progress; cancel and Save first
  if you want to keep it.

The previous split was for isolated development and playtesting, not a separate
engine or missing integration. One app now contains both experiences. Separate
route exports remain available only as developer previews, not public releases.

## Existing saves continue to work

The campaign retains
`~/Library/Application Support/Godot/app_userdata/Roman War/roman_war_save.json`.
Alpine Route retains
`~/Library/Application Support/Roman War Alpine Route/roman_war_save.json`.
The latter folder preserves compatibility with the old companion app; you do
not need that app installed. Save backups remain available at both locations.
Open the desired mode and press **Load** to resume. Starting or switching modes
does not overwrite either save. Saving replaces only that mode's slot.

No save files are moved or converted. Preview and QA builds remain isolated
from both production saves. Options are shared within the merged app.

## Verification and scope

Release gates: schema/data validation, complete Godot regression suite, package
contents and deterministic replay probe, native version/signature/architecture
checks, rendered map and route planning/crossing/arrival/maximum zoom, and a
packaged two-process save/load exercise covering both modes, return navigation,
route restart and protection of the campaign save. Exact results and source
hashes accompany the download in `BUILD-INFO.json` and `SHA256SUMS.txt`.

Tested on Apple M3 Max; the included Intel slice has not been tested on Intel
hardware. The app is ad-hoc signed, not Apple-notarized. If macOS blocks opening,
use **System Settings → Privacy & Security → Open Anyway** for the app.

Gameplay remains the audited 0.14.1 baseline. Battles still auto-resolve; this
release merges the launcher and distribution, not the two saved campaigns.
The [development roadmap](../ROADMAP.md) remains the next-work plan.
