# Roman War 0.14.0 — campaign terrain and cartography

The live campaign now opens in the procedural 3D terrain view, with shared UI
styling and generated commander, unit and construction illustrations. The
classic map remains an Options comparison.

Marsh affects march cost; authored ridges and unbridged rivers block land
routes; bridges and passes provide crossings and defensive advantages. Movement
quotes, execution, combat, AI traversal and land connections use the same
physical edges. The army panel reports its ground connection to the capital.

The atlas begins with the player's observers. Negotiated map access adds
geography without exposing live enemy armies. Acquired geography persists;
war ends future geographic updates. New save fields are additive.

This release includes the preceding map-order, commander and reconnaissance
work. The production app uses the normal faction/seed start menu and persistent
campaign saves. It does not use the preview app's per-process save directory.

## macOS download

`RomanWar-macOS-0.14.0.zip` contains **Roman War.app**, for Apple Silicon and
Intel Macs. Unzip and open the app. This local playtest distribution uses an
ad-hoc signature, not Apple Developer ID notarization; macOS may require its
Open Anyway flow. The game runs locally and does not require a server.

## Current limits

The original procedural art remains stylized rather than finished
photorealism. Elevation advantages are province-level, ground supply is a
connectivity report rather than a ration system, and the optional woods study
is staged presentation rather than a live ambush rule. Eleven crossing
examples are authored campaign constraints, not surveyed ancient geography.
