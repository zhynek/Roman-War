# Roman War 0.14.1-preview.20260926 — Mac feedback build

Historical preview record. The owner subsequently approved these changes for
[production release 0.14.1](0.14.1.md), which is the current Mac standard.

This local preview includes the latest Alpine-route work based on production
commit `3670aac`, plus the September 26 save-reliability and map-tooltip fixes.
The public GitHub release remains v0.14.0. These are universal release-mode Mac
apps with both Apple Silicon and Intel executable slices, tested on an Apple M3
Max. Intel execution and Apple notarization have not been verified.

## Choose an app

| App | Use it for | Location in the repository's local build directory |
|---|---|---|
| **Roman War Playtest** | Full campaign with faction, difficulty, seed and guided-mode selection | `build/playtest-2026-09-26/campaign/Roman War Playtest.app` |

Each folder also contains an approximately 57 MiB universal ZIP, its SHA-256
checksum, source snapshot, provenance manifest and verification logs. The ZIP
names end in `macOS-0.14.1-preview.20260926.zip`.

Unzip, then open the app; Godot installation is not needed. You can drag the
app into Applications if desired. These builds have verified **ad-hoc signatures**,
not Developer ID notarization. If macOS blocks a downloaded copy, use
**System Settings → Privacy & Security → Open Anyway** for this app, then confirm
the launch. See [Godot's macOS export guidance](https://docs.godotengine.org/en/4.4/tutorials/export/exporting_for_macos.html).

## Full-campaign feedback session

1. Select **House of the Julii**, **Medium**, seed **42**, with guided mode on.
   The default alphabetical house may be Cornelii; choose Julii for a comparable
   report. Begin the campaign.
2. Select your commander. Click a destination or press **M**, review the quote,
   and issue orders. Use **F** to find the commander and **V** for close view.
   Compare the 3D and classic map using Options.
3. Inspect a settlement, queue a building and recruitment, then play 10–20 turns.
   Try diplomacy, Knowledge, Senate, and a battle. Battles currently resolve
   automatically; their animated screen is not player-controlled tactical combat.
4. Press **Save**, quit, reopen, begin a campaign, then press **Load** in the
   campaign header. There is not yet a Continue button on the start menu.

## Alpine-route feedback session

Open the route app. Expand **Alpine Frontier**, select the next waypoint, inspect
its movement quote, then press **Issue orders**. Follow Pannonia → Illyria →
Venetia → Noricum → Raetia, ending the turn when movement runs out. At Noricum,
use **Patrol woods** to reveal the neighbouring column. Compare bridge/causeway/
pass clarity, troop scale, arrival placement and the classic view. Save/Load is
available; **Restart route** starts a new scenario.

The route is an authored campaign exercise with real game rules, not a separate
tactical simulation or a claim of reconstructed historical geography.

## Saves and recovery

The two apps use separate persistent save directories:

- Campaign: `~/Library/Application Support/Roman War Playtest/`
- Route: `~/Library/Application Support/Roman War Route Playtest/`

Each uses `roman_war_save.json` and keeps the previous valid save in
`roman_war_save.json.bak`. Load can recover from that backup when the main save
is missing or structurally invalid. It currently reports the normal “Game
loaded” message, so check the turn after recovery. Saving validates a temporary
file before replacement; this is not a guarantee against every storage/power
failure or every semantically corrupt nested value.

Production and the older route-development app's saves stay separate. No saves
were copied or migrated automatically. QA used disposable isolated directories.

## What to send back

Record **version, app/mode, faction, seed, turn, province, expected behavior and
actual behavior**. Include the save for gameplay issues and a screenshot for
visual problems. Most useful feedback now: whether issuing orders is clear,
whether AI actions feel fair, whether the route is visually convincing, and
which matters most next—tactical battles, campaign depth, interface or art.

next milestones.
