# Creative variants

The historical reference is `constantinople_1200 / constantinople_1200_ce`.
No creative variant has been built yet. This directory is the future workspace
for alternative designs, not an implemented in-game mode.

For each variant, create a named subfolder and record:

1. Stable variant ID, purpose, baseline snapshot and baseline revision/hash.
2. Which objects are retained, added, moved, enlarged, rebuilt or removed.
3. The authored geometry/parameter overrides and the reason for each change.
4. Which design stages include the change; dependencies such as street access,
   water, retaining structures and construction space.
5. Screenshots/render locations outside the repository and unresolved questions.

Preserve the baseline's source records. Label new work `creative`; a plausible
addition does not become an attested Byzantine building. A historical correction
belongs in the baseline with evidence, not in a creative override.

Example design brief: expand a waterfront ward with better storage and a broader
service street while retaining its original churches and waterfront connection.
That is a future what-if design, not a claim about what Constantinople built.
