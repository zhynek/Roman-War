# Byzantine Empire — city studies

The first study is [Constantinople around 1200 CE](cities/constantinople_1200/README.md),
selected by the project owner. "Byzantine Empire" is the conventional historical
label for the medieval Eastern Roman Empire; this is an imperial setting, not a
generic western feudal kingdom. Its connection to Roman history does not make it
contemporary with the existing Rome campaign.

This realm folder groups architectural and urban research. It does not add a
faction to `data/factions.json`, map onto the game's `eastern` culture, or establish
playable territory. Any such integration would need its own period and gameplay
design.

Study a city's governing, religious, military and commercial spaces on their own
evidence. Constantinople's palaces, churches and waterfront institutions should
not be forced into a universal castle-and-town-hall template. Consult the city's
[source register](cities/constantinople_1200/SOURCES.md) before adopting a regional
architectural trait.
